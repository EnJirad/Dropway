# 🗄️ Supabase Database Scripts — DropWay

โฟลเดอร์นี้รวบรวมไฟล์สคริปต์ SQL ทั้งหมดสำหรับจัดการฐานข้อมูลของโปรเจกต์ DropWay ผ่าน **Supabase SQL Editor**

---

## 📁 รายการไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ | วิธีใช้งาน |
|---|---|---|
| [`schema.sql`](./schema.sql) | **โครงสร้างฐานข้อมูลหลักทั้งหมด** (Tables, Views, Indexes, Triggers, RLS Policies) | ใช้สร้างฐานข้อมูลใหม่ทั้งหมด สามารถรันซ้ำได้โดยไม่พัง (Idempotent) |
| [`seed.sql`](./seed.sql) | **ข้อมูลตัวอย่างสำหรับทดสอบ** (บ้านตัวอย่าง 10 หลังพร้อมพิกัด GPS จริง) | รันหลังจากรัน `schema.sql` เพื่อให้มีข้อมูลทดสอบทันที |
| [`reset.sql`](./reset.sql) | **ลบตารางและวิวทั้งหมด** (Clean Wipe) | ใช้เมื่อต้องการล้างข้อมูลเพื่อเริ่มสร้างใหม่ตั้งแต่ต้น (ระวังข้อมูลหาย) |

---

## 🚀 วิธีรันสคริปต์ใน Supabase SQL Editor (แบบทีละขั้นตอน)

### ขั้นตอนที่ 1: เข้าสู่ Supabase SQL Editor
1. ล็อกอินเข้า [Supabase Dashboard](https://supabase.com/dashboard)
2. เลือกโปรเจกต์ของคุณ
3. คลิกเมนู **SQL Editor** ที่แถบเมนูด้านซ้าย (ไอคอน `>_`)

### ขั้นตอนที่ 2: รัน `schema.sql` (สร้างตาราง)
1. กดปุ่ม **+ New query** (มุมบนซ้ายของหน้า SQL Editor)
2. เปิดไฟล์ [`supabase/schema.sql`](./schema.sql) ในโปรเจกต์นี้
3. คัดลอกเนื้อหาทั้งหมดมาวางในช่อง Query
4. กดปุ่ม **Run** (หรือกดคีย์ลัด `Ctrl + Enter` บน Windows / `Cmd + Enter` บน Mac)
5. เมื่อสำเร็จจะขึ้นข้อความ `Success. No rows returned`

### ขั้นตอนที่ 3: (ทางเลือก) รัน `seed.sql` (เพิ่มข้อมูลทดสอบ)
1. กด **+ New query** อีกครั้ง
2. คัดลอกเนื้อหาจากไฟล์ [`supabase/seed.sql`](./seed.sql) มาวาง
3. กดปุ่ม **Run**
4. ข้อมูลบ้านตัวอย่าง 10 หลังจะถูกบันทึกลงในตาราง `houses` ทันที

### ขั้นตอนที่ 4: ตรวจสอบความถูกต้อง
เปิด Terminal ในโปรเจกต์ แล้วรันคำสั่งตรวจสอบ:
```bash
npm run test:supabase
```
สคริปต์จะแสดงเครื่องหมาย `✓` สีเขียวครบทุกตาราง แปลว่าพร้อมใช้งาน 100%!

## 🛡️ ข้อมูล Row Level Security (RLS)

- **`houses`**: ผู้ใช้ที่ผ่านการยืนยันตัวตน (Authenticated User) สามารถ ค้นหา, เพิ่ม, แก้ไข และลบข้อมูลบ้านได้
- **`user_navigation_houses`**: คนขับแต่ละคนสามารถเข้าถึงและแก้ไขเฉพาะรายการนำทางที่เป็นของตนเอง (`auth.uid() = user_id`)
- **`navigation_view`**: ใช้สิทธิ์ความปลอดภัยตรงตามตารางต้นทาง (`security_invoker = true`)
